Library Book Management System

Static File Served via Node.js FS Module

Welcome to the Library Management Web Application home portal. This static HTML page is served directly through Node.js using the native fs module on the /home route.

Application Modules

Part A: Native HTTP Server

Runs on port 3000 using Node.js built-in http and fs modules. Handles custom routing, HTTP GET/POST, and static file serving.

Part B: Express.js REST API

Runs on port 4000 using Express.js. Provides complete CRUD operations (GET, POST, PUT, DELETE) for books management with JSON responses.

Available HTTP Server Routes (Port 3000)

Method Route Description
GET / Welcome message in HTML format
GET /books Returns list of all available books in JSON format
GET /about Application information
GET /home Serves this static HTML file using FS module
POST /add-book Accepts JSON book details (id, title, author, price)

Express.js REST API Endpoints (Port 4000)

Method Endpoint Description
GET /books Retrieve all book records
GET /books/:id Retrieve a single book record by ID
POST /books Add a new book record (Status 201)
PUT /books/:id Update book details by ID
DELETE /books/:id Delete a book record by ID
